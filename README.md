# Revisão de Python

Este repositório contém exercícios e práticas desenvolvidas durante meus estudos de Python, com foco em reforçar conceitos fundamentais e evoluir na linguagem.

---

##  Estrutura do Projeto

O projeto está organizado em pastas por temas:

- **Fundamentos** → conceitos básicos da linguagem
- **POO** → Programação Orientada a Objetos
- **Projetos** → pequenos projetos práticos
- **Modularizar Arquivos** → organização de código em módulos

---

## Tecnologias Utilizadas

- Python 3

---

## Conteúdos abordados

- Estruturas condicionais (`if`, `else`)
- Laços de repetição
- Funções
- Listas, conjuntos e dicionários
- Programação Orientada a Objetos (POO)

---

##  Objetivo

Consolidar conhecimentos em Python e desenvolver lógica de programação através da prática.
